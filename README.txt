DARKO SMART TECH — WEBSITE STARTER

Files:
- index.html: complete responsive storefront in one file.

Before publishing:
1. Replace the sample products, descriptions and GH₵ prices with your actual stock and prices.
2. Add real product photos (the current product visuals are emoji placeholders).
3. Add the exact shop address, opening hours, and any delivery/pickup information.
4. Test the WhatsApp order flow on a phone.

Quick publishing:
- Netlify: create/sign in to an account, then drag the folder containing index.html into the Netlify deploy area.
- GitHub Pages: create a repository, upload index.html, then enable Pages in repository settings.
The site is static and does not yet include online card/mobile-money payment or a secure inventory/admin backend.
