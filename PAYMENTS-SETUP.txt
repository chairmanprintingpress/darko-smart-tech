DARKO SMART TECH — PAYMENT SETUP

Included:
- Paystack hosted checkout for GHS card and mobile money payments.
- Server-side price calculation (frontend prices cannot be trusted).
- Server-side payment verification after the checkout redirect.
- Paystack webhook signature validation endpoint.
- WhatsApp order/enquiry flow remains available separately.

Before accepting real payments:
1. Create/complete your Paystack merchant account and obtain your API keys.
2. Install Node.js 18+.
3. Run npm install in this folder.
4. Copy .env.example to .env and add your Paystack TEST secret key.
5. Set SITE_URL=http://localhost:3000 and run npm start.
6. Test using Paystack test credentials.
7. Deploy this Node.js project to a Node-compatible host with HTTPS.
8. Set PAYSTACK_SECRET_KEY to your LIVE secret key in the host's environment variables and SITE_URL to your live HTTPS website.
9. Add https://YOUR-DOMAIN/api/paystack-webhook as the webhook URL in Paystack dashboard.

NEVER put your Paystack secret key in index.html, publish it in a repository, or send it in chat.
The actual merchant account, API keys, and live payment activation are not included; only the integration code is prepared.

IMPORTANT PRODUCT DATA:
Sample products and prices are placeholders. Update prices in BOTH public/index.html and server.mjs before launch.
This starter does not yet include a database, admin dashboard, stock control, or automatic order notification to the store. Confirm paid orders in the Paystack dashboard before releasing goods.
